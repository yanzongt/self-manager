# 行为闭环 · PDCA

Ubuntu 24 + XFCE 推荐从桌面终端运行：

```sh
cd /home/yzt/code/self-manager
python3 serve.py
```

自动打开 <http://127.0.0.1:8765>。点击「发送测试提醒」验证桌面通知和提示音。
服务仅监听本机，使用 Python 标准库和系统 `notify-send`，无需 Python 依赖。
如缺少通知组件：`sudo apt install libnotify-bin xfce4-notifyd`。

计时开始、延期和结束时会同步系统提醒。只要终端中的服务仍在运行，标签页在后台甚至关闭后也会发送已安排的提醒。提示音和复盘层仍需要页面运行；系统挂起期间不能提醒，恢复后发送逾期提醒。Ctrl+C 停止服务。服务重启后，需要重新打开页面才能从浏览器存储恢复计时并重新安排提醒。

直接打开 `pdca_focus.html` 仍可使用浏览器通知，但必须允许网站通知，保持标签页打开；浏览器休眠、后台节流和文件地址权限限制可能影响提醒。提示音在点击「开始计时」或测试按钮时初始化，刷新后需再次点击测试按钮启用声音。

如果测试通知未显示，在 XFCE 的「设置 → 通知」检查勿扰模式和应用通知设置。也可在桌面终端执行 `notify-send '测试' '桌面提醒'` 检查系统通道。网页的测试成功仅代表通知请求成功，不能判断通知气泡是否被桌面设置隐藏。

数据继续保存在浏览器 localStorage 中。**文件地址与本机 HTTP 地址的存储彼此独立**：首次切换前在旧页面「备份 JSON」，到新页面「恢复 JSON」，避免误以为历史记录丢失。固定使用同一个端口；不同端口的存储也独立。本地服务不保存历史数据或当前计时到磁盘。

验证通知服务：`python3 -m unittest -v test_serve.py`。验证评论功能：`node test_comments.cjs`。

验证番茄钟和工作事项：`node test_focus.cjs`。

## 番茄钟

开始工作会话时自动进入 Work。默认 Work 25 分钟、Break 5 分钟，可在开始前调整。勾选「自动切换 Work / Break」后，在会话预算内循环切换并发送阶段提醒；取消勾选后，阶段结束时提醒并等待点击「开始下一阶段」。运行中可修改自动切换开关。

会话总预算包含 Work、Break 和手动切换的等待时间；总预算到时优先停止番茄钟并进入复盘。提前结束会保存未完成阶段的实际时长。到时复盘后延期会启动新的 Work 阶段；未到时的延期继续当前阶段。

阶段记录包含类型、开始/结束时间、时长及完成/提前结束状态，随会话保存，在历史记录中展开查看。完整 TXT、单条历史记录 TXT 和 JSON 备份均包含番茄钟记录。刷新后按保存的时间戳恢复；自动模式会补齐已经过的计划阶段，仅提醒当前状态，避免补发大量通知。记录代表计时阶段，不代表实际专注的证明。

直接打开 HTML 使用浏览器通知，后台冻结可能延迟切换提醒；通过本地服务打开时，系统通知由独立调度器发送，页面恢复后同步阶段记录。此次服务代码也已更新，使用本地模式需停止并重新运行 `python3 serve.py`，再刷新页面。

## Work items 四象限

填写事项标题，分别勾选「重要」和「紧急」，保存后自动进入对应象限。支持编辑标题/分类、标记完成、恢复待办和删除；默认隐藏已完成事项，可勾选显示。点击「用于本次工作」会填写会话目的并关联任务，再点击「开始计时」。完成一次会话不会自动把任务标记完成，任务状态由你单独确认。

任务与关联关系保存到浏览器本地存储，随 JSON 备份和恢复。单条会话导出保留关联事项标题。删除或改名任务不会改变之前已保存的会话标题。旧备份可以继续导入；旧会话没有的番茄钟阶段不会凭空补写。

运行中可在「随手评论」输入进展或想法，点击「添加评论」立即保存，并记录精确到秒的添加时间。评论随会话保留，延期、刷新和结束复盘后仍可查看。在当前会话和历史记录中，每条评论都有「导出此条 TXT」按钮，导出包含项目、目的、添加时间和评论内容。全部 TXT 导出和 JSON 备份也包含评论；旧备份仍可恢复。

历史记录每行的「导出记录 TXT」可单独导出该次完整会话，包含开始和结束时间、项目、目的、计划/延长/实际时长、完成状态、复盘、阶段复盘及全部评论和添加时间。

HTML 文件保存界面和程序代码；工作记录、标签、当前会话和评论由浏览器保存在自己的用户配置目录中，使用 localStorage 的 `focus_pdca_singlefile_v1` 键存储 JSON，并不会写回 HTML，也不会写入项目文件夹。通常刷新、关闭网页和重启浏览器后数据仍在；清除网站数据、使用隐私窗口或更换浏览器/用户配置/访问地址会影响数据可见性或保留情况。浏览器开发者工具的「Application / 应用 → Local Storage / 本地存储」可查看该键。复制 HTML 文件不会携带记录，迁移和长期保留请使用「备份 JSON」。
