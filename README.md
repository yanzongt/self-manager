# 行为闭环 · PDCA

Ubuntu 24 + XFCE 推荐从桌面终端运行：

```sh
cd /home/yzt/code/self-manager
python3 serve.py
```

自动打开 <http://127.0.0.1:8765>。点击「发送测试提醒」验证桌面通知和提示音。
服务仅监听本机，使用 Python 标准库和系统 `notify-send`，无需 Python 依赖。
如缺少通知组件：`sudo apt install libnotify-bin xfce4-notifyd`。

计时开始、延期和结束时会同步系统提醒。只要终端中的服务仍在运行，标签页在后台甚至关闭后也会发送已安排的提醒。提示音和复盘层仍需要页面运行；系统挂起期间不能提醒，恢复后发送逾期提醒。Ctrl+C 停止服务。服务重启后会从本机数据文件恢复已保存的计时提醒；页面刷新后恢复计时界面。

需要通过 `python3 serve.py` 打开页面才能读写本机数据文件。直接打开 HTML 时只能导出该地址下的旧浏览器数据。使用浏览器通知必须允许网站通知并保持标签页打开，浏览器休眠或后台节流可能影响提醒。提示音在点击「开始计时」或测试按钮时初始化，刷新后需再次点击测试按钮启用声音。

如果测试通知未显示，在 XFCE 的「设置 → 通知」检查勿扰模式和应用通知设置。也可在桌面终端执行 `notify-send '测试' '桌面提醒'` 检查系统通道。网页的测试成功仅代表通知请求成功，不能判断通知气泡是否被桌面设置隐藏。

## 本机文件存储

标签、工作事项、评论、历史记录、当前会话和番茄钟设置统一保存在项目目录的 `data/pdca.json`。文件在首次打开服务页面并成功保存时创建；路径相对于 `serve.py`，不受启动终端的工作目录影响。页面顶部显示读取、保存或失败状态，收到服务端确认后才显示「已保存」。同一服务的数据可以在不同浏览器中读取，清理浏览器数据不会删除本机文件。

服务端写入采用临时文件、刷新到磁盘后原子替换，每次数据发生变化时将上一份文件保留为 `data/pdca.json.bak`。这个备份仅保留上一版，长期备份仍使用「备份 JSON」。`data/` 已加入 `.gitignore`。如果文件损坏，页面停止加载并提示，避免用空数据覆盖；停止服务后可将 `.bak` 复制回正式文件，再重启服务。

首次使用新版本时，如果文件尚不存在，会自动迁移**当前访问地址**下的旧浏览器数据，迁移后原浏览器数据保留。如果原来直接打开 HTML、使用另一端口或另一浏览器，在旧地址打开 HTML，点击顶部「导出旧浏览器数据」，然后在服务页面通过「恢复 JSON」导入。已有本机文件时始终优先读取文件，不会被旧浏览器记录自动覆盖。恢复 JSON 会覆盖本机文件，操作前页面会提示确认。

保存失败时，修改暂留在当前页面，可「重试保存」或导出 JSON；离开页面会提示未保存。多个页面同时修改时，服务端拒绝过期版本写入：先导出未保存的修改，再「重新读取」最新文件，按需手动合并。建议集中在一个页面编辑。本地接口使用页面令牌，写入同时检查请求来源。

可指定其他数据位置：

```sh
python3 serve.py --data-file /path/to/pdca.json
```

验证文件读写和通知调度：`python3 -m unittest -v test_serve.py`。验证页面迁移、保存、评论、番茄钟、导入、失败重试和冲突处理：`node test_storage.js`。

## 番茄钟

番茄钟有独立面板，点击「启动番茄钟」即可开始 Work，无需填写目的或创建工作会话。默认 Work 25 分钟、Break 5 分钟，关闭后可调整时长。点击「关闭番茄钟」取消阶段计时和后续提醒；运行中随时点击「切换到 Work / Break」从当前时间开始下一阶段。

勾选「自动切换 Work / Break」后循环切换并提醒；取消后，到时提醒并等待手动开始下一阶段。番茄钟与工作会话互不影响：开始、结束、到时和延期工作会话均不会启动或停止番茄钟。番茄钟不新增阶段记录，也不出现在会话历史或 TXT 导出中；旧备份中的原始记录仍保留在 JSON 内。

刷新后按时间戳恢复独立番茄钟；自动模式只提醒当前阶段，避免大量补发。旧数据中尚在运行的番茄钟会迁移为独立计时器。通过本地服务打开时优先使用 `notify-send` 独立调度，系统通道不可用时使用已授权的浏览器通知。更新后需重启 `python3 serve.py` 并刷新页面。

## Work items 四象限

填写事项标题，分别勾选「重要」和「紧急」，保存后自动进入对应象限。支持编辑标题/分类、标记完成、恢复待办和删除；默认隐藏已完成事项，可勾选显示。点击「用于本次工作」会填写会话目的并关联任务，再点击「开始计时」。完成一次会话不会自动把任务标记完成，任务状态由你单独确认。

任务与关联关系保存到本机数据文件，随 JSON 备份和恢复。单条会话导出保留关联事项标题。删除或改名任务不会改变之前已保存的会话标题。旧备份可以继续导入；旧会话没有的番茄钟阶段不会凭空补写。

运行中可在「随手评论」输入进展或想法，点击「添加评论」立即保存，并记录精确到秒的添加时间。评论随会话保留，延期、刷新和结束复盘后仍可查看。在当前会话和历史记录中，每条评论都有「导出此条 TXT」按钮，导出包含项目、目的、添加时间和评论内容。全部 TXT 导出和 JSON 备份也包含评论；旧备份仍可恢复。

历史记录每行的「导出记录 TXT」可单独导出该次完整会话，包含开始和结束时间、项目、目的、计划/延长/实际时长、完成状态、复盘、阶段复盘及全部评论和添加时间。

HTML 文件保存界面和程序代码；数据由 `serve.py` 写入本机文件，不会写回 HTML。迁移到其他电脑时可复制整个 `data/` 目录，或在新服务页面恢复导出的 JSON 备份。
