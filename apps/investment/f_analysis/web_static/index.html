让研究更简单

  1. 配置股票池

    使用 Yahoo 代码，上海为 .SS、深圳为 .SZ。权重合计不超过 100%，其余为现金。

  2. 选择策略与参数

    可同时比较多个策略。MA30 / MA120 表示有效交易日数量，偏离 5% 对应均线的 95% / 105%。

  3. 运行并查看结果

    结果自动保存在 outputs/web_backtest/。可导出全部报告，在「记录」中随时重新打开。

本地缓存不会自动更新。离线模式不会联网；刷新模式重新下载本次股票的完整历史。
