# 传感器视场 · Sensor FOV

个人工具主页的第五个工具，使用 Vue、TypeScript、Vite 和 Three.js，在浏览器中编辑传感器布局并检查三维视场。页面引用 `apps/shared/theme.css`，采用统一的 Self Manager 浅色界面。

## 启动与构建

从仓库根目录运行：

```sh
./start.sh
```

访问 <http://127.0.0.1:8765/sensor-fov/>，也可从主页进入。首次启动会自动安装缺失依赖并构建，需要 Node.js 22.12+、npm 和网络。工具使用现有 Python HTTP 服务，无需独立服务器、额外端口或额外 Python 依赖；浏览器运行需要 WebGL 2，不访问 CDN 或外部数据服务。

修改源码后运行：

```sh
./apps/sensor-fov/setup.sh
npm run build --prefix apps/sensor-fov
npm test --prefix apps/sensor-fov
npm run test:browser --prefix apps/sensor-fov
```

浏览器测试使用临时服务和独立浏览器上下文，需要 Chrome，默认路径 `/usr/bin/google-chrome`，可通过 `CHROME_PATH` 指定。截图可通过 `FOV_SCREENSHOT_PREFIX` 指定路径。`npm run format --prefix apps/sensor-fov` 用于整理源码格式。

依赖、自动生成的锁文件、构建资源和截图统一放在被 Git 忽略的 `.generated/`；`node_modules` 只是本地链接。不要提交这些生成物。

## 网页使用

- 左侧选择类型并添加传感器，数量由列表决定，支持 0 ～ 100 个。
- 每个传感器可编辑名称、XYZ、Roll/Pitch/Yaw、距离、FOV、颜色和不透明度；选中后可以复制或删除。复选框控制显示。
- 激光雷达可编辑水平全角与垂直仰角上下限；相机可编辑水平/垂直全角；超声波可编辑圆锥全角。
- 展开“地面与车体”可编辑地面高度、尺寸、激光落地点，以及车体底面中心、四个 XY 顶点和高度。四个顶点自动按极角排序，必须形成非退化凸四边形。
- 顶部切换 3D、俯视、前视、侧视，支持适配视图和 PNG 截图；方向与传感器名称采用透明底色，可通过「隐藏文字 / 显示文字」一键切换，当前页面编辑期间保持该显示状态；右下角可仅显示某类传感器。
- 左键旋转，右键平移，滚轮缩放；点击安装点也可选中传感器。
- 编辑期间保留观察视角。布局变化后可点击“适配视图”；导入/恢复默认布局会自动适配。

有效配置会在编辑停止约 100 ms 后保存到浏览器 `localStorage`，刷新恢复。它按 **协议、主机和端口** 区分，换地址或换浏览器不会共享配置。无法使用本地存储时显示提示，仍可手动导出 JSON。JSON 导入会整体替换当前配置，不合并列表；建议先导出当前方案。默认布局恢复操作有确认提示。

JSON 文件包含 `version: 1`、`sensors`、`ground` 和 `vehicle`，导出的文件就是完整示例。导入限 1 MB，严格检查字段、有限数值、角度范围、数量和唯一 ID。非法导入保留原配置；表单临时无效时提示原因，画面/存储保留上一次有效值，修正后继续更新。导入导出仅针对新网页的 JSON 格式。

## 几何约定

- 位置单位 **m**，姿态/FOV 单位 **°**，坐标为 **X 前、Y 左、Z 上**。传感器位置相对于世界/车体原点；移动车体盒子不联动传感器位置。
- 局部点通过 `p_world = Rz(yaw) × Ry(pitch) × Rx(roll) × p_local + pos` 变换。正 Pitch 会将局部 +X 轴向下转。
- **LiDAR**：方位角以局部 +X 为中心，范围 `[-水平FOV/2, +水平FOV/2]`；垂直角为相对局部 XY 平面的仰角，支持非对称上下限。距离为球面半径，水平全角可到 360°。
- **相机**：以局部 +X 为前向，四棱锥底面位于 `x = d`，半宽 `d × tan(hFov/2)`，半高 `d × tan(vFov/2)`。深度不是角点到光心的球面距离。这里不是 ROS 相机 optical frame（Z 前、X 右、Y 下），使用 optical frame 外参前需要转换。
- **超声波**：沿局部 +X 展开的圆锥，底面 `x = d`、半径 `d × tan(fov/2)`。深度不是圆锥侧面长度；保持旧脚本的几何含义。
- 相机/超声波全角限制为 0.1 ～ 179°，避免 `tan(90°)` 发散。距离允许 0.01 ～ 1000 m；激光垂直角在 ±90° 内且下限小于上限。
- 激光落地采样使用当前位姿、当前 FOV 和**同一个最大距离**，仅保留 `t >= 0` 且 `t <= range` 的射线交点。地面边长只影响参考网格，不裁剪交点。旧脚本的 FOV 半径为 3 m、落地距离为 2.5 m；新实现统一采用可编辑的 3 m 默认值。
- 默认仍是原脚本实际启用的双激光布局，车体底面 X 范围 `[-0.261, 0.323]`、Y 范围 `[-0.27, 0.27]`、高度 `0.2 m`，相机/超声波通过“添加”启用。

视场为理想几何包络，地面交点是离散采样，无遮挡裁剪、探测概率、测距误差或多传感器融合。不代表真实探测结果。


## 目录与迁移

- `src/App.vue`：表单、传感器选择、浏览器存储、配置导入导出。
- `src/model.ts`：配置类型、默认布局、校验、坐标变换与射线交点。
- `src/scene.ts`：Three.js 几何、视角、拾取、PNG 截图与资源释放。
- `src/theme.ts`：读取共享主题，供三维画布使用。
- `src/NumberField.vue`、`src/style.css`：数值输入与工作台布局。
- `src/model.test.ts`、`test-browser.mjs`：几何/校验测试和实际浏览器回归。

浏览器存储键继续使用 `sensor-fov-config-v1`。与旧工具使用相同协议、主机、端口时可自动读取原配置；原来在其他端口使用的布局需要从原地址导出 JSON，再在新入口导入。路径变化不会影响同源的浏览器存储。

原根目录 `sensor_fov/` 中的旧 Python 绘图脚本、Plotly HTML、PNG 示例、单独的 Node 服务器/启动脚本和旧构建缓存不参与新工具运行，已从项目中移除。新网页保留原默认双激光布局及几何约定。
